# Week-Wise Project Plan

## Week 1: Setup

- Install Node.js, VS Code, Git, and Chrome.
- Create the React client and Express server.
- Connect the project to GitHub.

## Week 2: Frontend Layout

- Build the main editor workspace.
- Add Monaco Editor.
- Add toolbar buttons and output panel.

## Week 3: Backend APIs

- Create routes, controllers, and services.
- Add health, AI, and security endpoints.
- Test APIs with Thunder Client or Postman.

## Week 4: AI Features

- Add explain, fix, and generate actions.
- Connect frontend requests to backend AI routes.
- Add fallback responses for demos without an API key.

## Week 5: Security Scanner

- Detect SQL injection patterns.
- Detect `eval`.
- Detect hardcoded secrets.
- Detect unsafe HTML patterns.

## Week 6: Avatar Voice

- Add browser text-to-speech.
- Let the avatar read the latest result.
- Polish the interaction states.

## Week 7: Viva Documentation

- Add architecture diagram.
- Add sequence diagram.
- Add use case diagram.
- Prepare demo code examples.

## Week 8: Final Testing

- Test all buttons.
- Fix UI issues.
- Push final code to GitHub.
- Prepare presentation explanation.
